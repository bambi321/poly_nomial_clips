poly_nomial_clips · automation

From one YouTube link to posted Shorts

You give the pipeline a URL. Eight stages turn it into captioned 9:16 clips for YouTube Shorts, Instagram Reels and TikTok. Every stage writes a file into the repo, and nothing is published until you approve it.

    Build order

    Phase 1 · start here

    Find the moments

    stages 1–3

    URL in, ranked highlights.md out. Cheap to run, and it tests the hardest judgement call first.

    Phase 2

    Cut automatically

    stages 4–5

    ffmpeg cuts, face-tracked 9:16 framing and burned-in captions land in each video's clips/ folder.

    Phase 3

    Brand and publish

    stages 5–7

    A Remotion template for the channel look, then upload to all three platforms after you approve.

    Phase 4

    Run on its own

    stage 8 + watcher

    Watch favourite channels for new uploads, and feed performance back into the playbooks.

    Source video, transcript lines and scores on this page are examples, not real data. Media files stay out of git; only the Markdown records are committed.
